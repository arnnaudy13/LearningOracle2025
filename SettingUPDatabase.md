| SettingUPDatabase Tutorial |
 
1. Make sure to properly install all the the tools in README.md

2. While Installing oracle, make sure to remember 'username' and 'password' during the installation. This will be important (at least for me(?))

3. Then open SQL Plus on search bar and start, 
      'Enter user-name: sys as sysdba' 
      I have tried you can change the sys into anything but sys it's like default thing.
      also 'sysdba' is important. 
      Then Enter. 

4. then it will continue asking your password
      'Enter password:' Use the password you have created while installing Oracle. 
      While typing here, your poassword will not show/will not type anything. Then enter.

5. After that enter 'select * from tab;' still in SQL Plus. This will set up the enviroment more. 

6. Open Oracle SQL Developer

7. Click on the Green Plus Button and just fill all of it. The name of the connection can be anything. The rest is the same one you have set up (point 2). 
The Role need to be set SYSDBA

8. Then you are connected!
9. Open Navicat or any kinda of navigation program.
